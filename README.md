# 🤖 Telegram Support Bot

Бот для пересылки сообщений пользователей в Telegram-группу с поддержкой ответов.

## 📁 Структура проекта

```
telegram_bot/
├── bot.py                  # Точка входа
├── config.py               # 🔑 Токен и ID группы — сюда вписывать!
├── database.py             # Работа с SQLite
├── requirements.txt        # Зависимости
├── handlers/
│   ├── __init__.py
│   ├── user_handler.py     # Сообщения от пользователей (личка → группа)
│   └── group_handler.py    # Ответы из группы (группа → личка)
└── README.md
```

---

## ⚙️ Установка и запуск

### 1. Клонируйте / скопируйте проект

```bash
cd telegram_bot
```

### 2. Создайте виртуальное окружение

```bash
python3 -m venv venv
source venv/bin/activate        # Linux / macOS
# или
venv\Scripts\activate           # Windows
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте `config.py`

Откройте файл `config.py` и замените значения:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"   # 👈 Ваш токен от @BotFather
GROUP_ID  = -1001234567890          # 👈 ID вашей группы (отрицательное число)
```

### 5. Запустите бота

```bash
python bot.py
```

---

## 🔑 Как получить BOT_TOKEN

1. Откройте Telegram → найдите `@BotFather`
2. Отправьте `/newbot`
3. Введите имя и username бота
4. Скопируйте токен вида `7123456789:AAHxxxxxxx`

---

## 🆔 Как узнать GROUP_ID

**Способ 1 (через бота):**
1. Добавьте `@userinfobot` в вашу группу
2. Напишите в группе `/start` — бот покажет ID группы

**Способ 2 (через API):**
1. Добавьте вашего бота в группу как администратора
2. Отправьте любое сообщение в группу
3. Перейдите в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Найдите `"chat": {"id": -100XXXXXXXXXX}` — это и есть GROUP_ID

> ⚠️ GROUP_ID всегда отрицательный для групп, например: `-1001234567890`

---

## 🤖 Добавление бота в группу

1. Добавьте бота в группу
2. Назначьте бота **администратором** (нужно для чтения сообщений)
3. В настройках администратора достаточно включить: **"Чтение сообщений"**

## 🔄 Схема работы

```
Пользователь (личка)
        │
        │  Пишет сообщение боту
        ▼
      [Бот]
        │
        │  Пересылает в группу с инфо о пользователе
        ▼
    [Группа]
        │
        │  Участник делает Reply на сообщение
        ▼
      [Бот]
        │
        │  Пересылает ответ обратно пользователю
        ▼
Пользователь (личка) получает ответ
```

## 🛡 Антиспам

По умолчанию между сообщениями одного пользователя — **3 секунды**.
Изменить можно в `config.py`:

```python
ANTISPAM_DELAY: int = 3  # секунды
```

## 📦 База данных

SQLite файл `bot_database.db` создаётся автоматически при первом запуске.

Таблицы:
- `users` — зарегистрированные пользователи
- `antispam` — время последнего сообщения (для антиспама)
- `message_map` — связка ID сообщения в группе ↔ ID пользователя
